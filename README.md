# KOROLEVSKY XVII — Music Archive

Тёмный музыкальный архив, посвящённый релизам Королевского XVII. Сайт объединяет дискографию, информацию об артисте и ссылки на музыкальные площадки.

**Открыть сайт:** [ССЫЛКА_НА_САЙТ](https://noir-auto.github.io/korolevsky-xvii/)

## Что есть на сайте

- Главная страница с авторским тёмным оформлением и бордовыми акцентами.
- Раздел об артисте и избранном альбоме.
- Каталог треков с поиском и фильтрами.
- Карточки релизов с обложками и ссылками на страницы прослушивания.
- Ссылки на Apple Music, Звук и МТС Музыку.
- Адаптация для телефонов и компьютеров.
- Анимации появления блоков и эффекты при наведении.

## Технологии

HTML, CSS, JavaScript.

## Запуск

Открой `index.html` в браузере. Для загрузки шрифтов и обложек требуется подключение к интернету.

## Примечание

Независимый фанатский архив. Не связан с артистом или музыкальными площадками.
